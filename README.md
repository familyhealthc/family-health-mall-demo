# 家家健康药交网 · 前端 Demo

在线预览：https://familyhealthc.github.io/family-health-mall-demo/

独立静态前端，使用 HTML / CSS / JavaScript，无需安装依赖。GitHub Pages 从 main 分支根目录发布。

支持商品搜索、分类筛选、价格排序、商品详情、批量找药、本地采购清单和 CSV 导出，适配电脑与手机。

商品图片与资料来自家家健康药交网公开页面，价格为 2026-11-13 UTC 抓取的展示快照。主视觉来自 Unsplash：https://images.unsplash.com/photo-1576091160399-112ba8d25d1d 。

这是前端交互演示，未接入真实账号、库存、支付或订单系统。

本地预览：`python3 -m http.server 4178`。
